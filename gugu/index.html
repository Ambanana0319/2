    使用说明

    01
    原著

    导入新的 TXT，或复用已经切割和阅读过的原著。A 负责全书总控，B 负责逐章写作。

    02
    坐标

    L 决定改多大范围，D 决定写多细，W 是成品总长度，F 决定多大程度遵守原著。

    03
    规格

    约定作品类型、叙事重心、视角中心和结局气质。这些决定“读起来像什么”。

    04
    要求

    写下必须发生的变化、场面、关系和禁区。Gugu 只在确实影响大纲时追问。

    READ

    原著怎样被使用

    原著完整保存在本机。系统先建立分层切割和全书认识，后续每章只取回相关原文，不会反复发送整本书。

    WRITE

    章节怎样成为正文

    写作者只拿当前章节包；总控根据隐藏路线校验。草稿经确认后才进入正式连续性，未确认内容不会污染后文。

    SPOILER

    未来信息怎样隔离

    总控可以了解结局，但写作者只看到当前可知信息。隐藏路线放在阅读页的高级入口，并有二次剧透确认。

    RUN

    整本书怎样生成

    可以逐章生成，也可以一键连续生成。系统会逐章写作、校验、确认并保存；遇到无法自动修复的问题会停在原地。

    本地优先原著、索引、草稿和正式章节都保存在这台电脑；API 只接收当前任务所需材料。
