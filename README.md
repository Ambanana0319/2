# Demo 02

一套完全静态、可独立分享的交互演示站。

- Gugu：五章虚构海上故事、章节阅读、剧情航线、人物关系与阶段状态。
- Pengu：写作任务、四份大纲、滑板企鹅生成动画、六份候选比较与完整文章。
- 演示内容均为独立虚构数据，不来自真实项目或用户资料。
- 浏览器运行期间不连接模型接口，不上传输入，也不保存数据。

## 本地预览

```bash
npm run verify
python3 -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/`。

## 文件结构

```text
index.html          入口页
gugu/               故事与关系演示
pengu/              写作流程演示
verify.mjs          静态内容、资源和隐私检查
```

整个目录可直接部署到 GitHub Pages，不需要构建步骤或后端服务。
